KTEM – All or Nothing

KTEM (Kaikki tai ei mitään, "All or Nothing") is a Veikkaus draw game in which 12 numbers are drawn from the range 1–24.

Menu command

Select Lotto Options → KTEM CSV…

Data file

The program reads data\KTEM.csv. The file has 12 semicolon-separated columns.

Dialog settings

  • Number of Rows – Number of suggestion rows to generate (1–50, default 5).

Output

  1. The requested number of prediction rows, each containing 12 numbers.
  2. Statistical analysis of all 12 columns (see Statistical Analysis).
Note: Because of the narrow number range (1–24), values across different columns tend to be close to each other. This results in a narrower statistical distribution compared to, for example, Suomen Lotto.
