KTEM

KTEM – All or Nothing

KTEM (Kaikki tai ei mitään, "All or Nothing") is a Veikkaus draw game in which 12 numbers are drawn from the range 1–24.

Menu command

Select Lotto Options → KTEM CSV…

Data file

The program reads data\KTEM.csv. The file has 12 semicolon-separated columns.

Dialog settings

  • Number of Rows – Number of suggestion rows to generate (1–50, default 5).
  • Stake per row – Select €1.00–€5.00 in €0.50 steps. The default is €1.00.
  • Onnenapila – Select this add-on to double the stake per row. It is off by default.

Checking winnings

Winnings are calculated from the selected stake per row and the multiplier for the number of matches. Zero and 12 matches are jackpots; match classes 5–7 have no prize. The program shows each row's winnings and their total. The database does not include the Onnenapila result, so its possible fourfold bonus is not included.

Output

  1. The requested number of prediction rows, each containing 12 numbers.
  2. Statistical analysis of all 12 columns (see Statistical Analysis).
Note: Because of the narrow number range (1–24), values across different columns tend to be close to each other. This results in a narrower statistical distribution compared to, for example, Suomen Lotto.

Dialog strategies

The dialog offers 8 optional strategies. Tick the check boxes for the ones you want. Frequency analysis is always used as the base; selected strategies are added on top.

  • Balanced – Approx. 50% small (1–12) and 50% large (13–24) numbers, and 50% even and 50% odd.
  • Delta technique – Randomly selects distinct numbers in ascending order within the minimum and maximum values in the historical data.
  • Wheel system – Enter at least 13 numbers in the Numbers field; all combinations are listed up to 100, otherwise 100 unique combinations are sampled at random.
  • Unusual numbers – Favours numbers above 31 with triple weight (has no practical effect in KTEM since the maximum is 24).
  • Consecutive pair – Includes at least one consecutive pair when the available numbers allow it.
  • Magic sum – Targets 80–120% of the frequency-weighted expected sum. If no sampled row meets the range, the closest sampled row is shown and marked.
  • Matrix technique – Builds a 3×3 matrix and uses its row, column, and diagonal sums as candidate numbers.
  • Portfolio Coverage – Favors numbers used less often in earlier generated rows and avoids duplicate main-number combinations where possible.

Draws are independent random events. These methods change the structure of suggested rows, not the chance that an individual valid line will win.

The strategies in use are recorded at the bottom of the results, e.g. Active strategies: Consecutive, Matrix.
