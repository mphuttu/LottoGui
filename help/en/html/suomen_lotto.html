SUOMEN LOTTO

Suomen Lotto CSV

Suomen Lotto is a Finnish national lottery organised by Veikkaus, in which 7 numbers are drawn from the range 1–40.

Menu command

Select Lotto Options → Suomen Lotto CSV…

Data file

The program reads data\SuomenLottoData.csv. The file has 7 semicolon-separated columns for the drawn numbers.

Dialog settings

  • Number of Rows – Number of suggestion rows to generate (1–50, default 5).
  • Plus – Select Plus to increase the row price from €1.00 to €1.50. It is off by default.

Output

The main window displays:

  1. The requested number of prediction rows – each row contains 7 numbers selected by frequency-weighted random selection.
  2. Statistical analysis of all 7 columns (see Statistical Analysis).

Prediction algorithm

The program calculates the frequency of all observed values for each column. More frequently occurring values receive a higher probability of being selected. Numbers within each row are always distinct.

Reminder: Historical frequency does not guarantee future results. Predictions are statistically based suggestions, not certainties.

Dialog strategies

The dialog offers 8 optional strategies. Tick the check boxes for the ones you want. Frequency analysis is always used as the base; selected strategies are added on top.

  • Balanced – Approx. 50% small (1–20) and 50% large (21–40) numbers, and 50% even and 50% odd.
  • Delta technique – Randomly selects distinct numbers in ascending order within the minimum and maximum values in the historical data.
  • Wheel system – Enter at least 8 numbers in the Numbers field; all combinations are listed up to 100, otherwise 100 unique combinations are sampled at random.
  • Unusual numbers – Favours numbers above 31 with triple weight.
  • Consecutive pair – Includes at least one consecutive pair when the available numbers allow it.
  • Magic sum – Targets 80–120% of the frequency-weighted expected sum. If no sampled row meets the range, the closest sampled row is shown and marked.
  • Matrix technique – Builds a 3×3 matrix and uses its row, column, and diagonal sums as candidate numbers.
  • Portfolio Coverage – Favors numbers used less often in earlier generated rows and avoids duplicate main-number combinations where possible.

Draws are independent random events. These methods change the structure of suggested rows, not the chance that an individual valid line will win.

The strategies in use are recorded at the bottom of the results, e.g. Active strategies: Balanced, MagicSum.
