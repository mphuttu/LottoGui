KENO

Keno CSV

Keno is a fast draw game by Veikkaus in which 20 numbers are drawn from the range 1–70. A player may select 1–10 numbers to match. The program generates 10-number suggestions.

Menu command

Select Lotto Options → Keno CSV…

Data file

The program reads data\KenoData.csv. The file contains 20 columns for all drawn numbers, separated by semicolons. The program automatically filters out zeros and malformed rows.

Dialog settings

  • Number of Rows – Number of suggestion rows to generate (1–50, default 5).

Output

  1. The requested number of prediction rows, each containing 10 numbers in the range 1–70.
  2. Statistical analysis of all 20 columns (see Statistical Analysis).
Tip: In a Keno draw all 20 numbers are drawn every round, but the statistical analysis covers all of them on a per-column basis. This gives a broad picture of how often numbers appear at each draw position.
Note: The program accepts only values in the range 1–70 as valid Keno data. Zeros and out-of-range values are removed during data import.
