KENO

Keno CSV

Keno is a fast draw game by Veikkaus in which 20 numbers are drawn from the range 1–70. A player selects a level from 2 to 10; the program generates suggestions with that many numbers.

Menu command

Select Lotto Options → Keno CSV…

Data file

The program reads data\KenoData.csv. The file contains 20 columns for all drawn numbers, separated by semicolons. The program automatically filters out zeros and malformed rows.

Dialog settings

  • Number of Rows – Number of suggestion rows to generate (1–50, default 5).
  • Level – Select 2–10 picks per row. The default is level 10.
  • Stake – Select €0.50–€10.00 in €0.50 steps. The default is €1.00.
  • Kunkkukerroin – Select this add-on to double the stake per row. It is off by default.

Checking winnings

Winnings are calculated by multiplying the selected stake by the multiplier for the selected level and number of matches. With Kunkkukerroin, the Kunkku multipliers are used with the selected base stake, even though the row price is doubled. After checking results, the program shows each row's winnings and their total. Level 11 is not available in the program.

Output

  1. The requested number of prediction rows, each containing the selected level's number of picks in the range 1–70.
  2. Statistical analysis of all 20 columns (see Statistical Analysis).
Tip: In a Keno draw all 20 numbers are drawn every round, but the statistical analysis covers all of them on a per-column basis. This gives a broad picture of how often numbers appear at each draw position.
Note: The program accepts only values in the range 1–70 as valid Keno data. Zeros and out-of-range values are removed during data import.

Dialog strategies

The dialog offers 8 optional strategies. Strategies apply to the selected number of picks (1–70). Tick the check boxes for the ones you want.

  • Balanced – Approx. 50% small (1–35) and 50% large (36–70) numbers, and 50% even and 50% odd.
  • Delta technique – Randomly selects distinct numbers in ascending order within the minimum and maximum values in the historical data.
  • Wheel system – Enter at least 11 numbers in the Numbers field; all combinations are listed up to 100, otherwise 100 unique combinations are sampled at random.
  • Unusual numbers – Favours numbers above 31 with triple weight.
  • Consecutive pair – Includes at least one consecutive pair when the available numbers allow it.
  • Magic sum – Targets 80–120% of the frequency-weighted expected sum. If no sampled row meets the range, the closest sampled row is shown and marked.
  • Matrix technique – Builds a 3×3 matrix and uses its row, column, and diagonal sums as candidate numbers.
  • Portfolio Coverage – Favors numbers used less often in earlier generated rows and avoids duplicate combinations where possible.

Draws are independent random events. These methods change the structure of suggested rows, not the chance that an individual valid line will win.

The strategies in use are recorded at the bottom of the results, e.g. Active strategies: Unusual, Consecutive.
