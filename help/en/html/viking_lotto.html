VIKING LOTTO

Viking Lotto CSV

Viking Lotto is a joint Nordic lottery game in which 6 main numbers are drawn from the range 1–48 and 1 Viking number from the range 1–5.

Menu command

Select Lotto Options → Viking Lotto CSV…

Data file

The program reads data\VikingData.csv. The file has 6 semicolon-separated columns for the main numbers. The Viking number is not stored in the historical data.

Dialog settings

  • Number of Rows – Number of suggestion rows to generate (1–50, default 5).

Output

  1. The requested number of prediction rows. Each row contains:
    • 6 main numbers (1–48), selected by frequency weighting
    • 1 Viking number (1–5), selected randomly
  2. Statistical analysis of all 6 main-number columns (see Statistical Analysis).
Note: The Viking number is always drawn randomly (1–5) because historical Viking number data is not stored in the CSV file. The prediction of the 6 main numbers is based on frequency data as normal.
