CSV File Format

LottoGui reads historical draw data in CSV format (Comma-Separated Values). The program uses a semicolon (;) as the column separator.

General structure

  • One draw round per line.
  • Columns separated by a semicolon ;.
  • Values must be integers.
  • The program automatically ignores empty lines and zero values (exception: Jokeri, where 0 is a valid digit).

4;0;7;7;2;9;1

File location

CSV files are stored in the data\ subfolder of the application's installation directory:

C:\Program Files\LottoGui\data\

Reminder: Keep your data files up to date by appending new draw results to the end of the files. The more historical data available, the more reliable the statistical analysis.
