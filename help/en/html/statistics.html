Statistical Analysis

LottoGui calculates a comprehensive statistical analysis for every CSV column. The statistics are based on all draw results in the data file for that column.

Calculated statistics

StatisticDescription
N (observation count) How many valid values the column contains.
Min The smallest observed value in the column.
Max The largest observed value in the column.
Mean (arithmetic) Sum of values divided by count. Represents the "centre of gravity" of the distribution.
Median The middle value when all values are sorted; half the values lie below and half above it.
Mode The most frequently occurring value (or multiple values in case of a tie).
Lower quartile Q1 The value below which 25% of observations fall.
Upper quartile Q3 The value below which 75% of observations fall.
Harmonic mean $n / \sum_{i=1}^{n} \frac{1}{x_i}$
Particularly suited for rate quantities. Shown as N/A if the column contains a zero (Jokeri).
Geometric mean $\left(\prod_{i=1}^{n} x_i\right)^{1/n}$
The n-th root of the product of all values. Describes relative growth.
Root mean square (RMS) $\sqrt{\frac{1}{n}\sum_{i=1}^{n} x_i^2}$
Square root of the mean of squared values.
Standard deviation $\sigma = \sqrt{\frac{1}{n}\sum_{i=1}^{n}(x_i - \bar{x})^2}$
Measures the spread of values around the mean. A small value indicates a tight distribution.

Interpreting the statistics

The statistics can be used to determine:

  • Whether a particular number has appeared exceptionally often or rarely.
  • Whether the column distribution is symmetric (median ≈ mean).
  • How wide a variation the numbers have shown (standard deviation, quartiles).
Reminder: Lottery draws are independent events. Statistical analysis describes the past, and no statistic can predict future draw results. Use the data as a reference aid, not as absolute predictions.
