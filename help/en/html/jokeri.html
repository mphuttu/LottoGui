JOKERI

Jokeri CSV

Jokeri is a side game played alongside Suomen Lotto, organised by Veikkaus. Seven digits are drawn, each from the range 0–9. The same digit may appear in more than one position on the same row – all seven positions could even show the same digit.

Menu command

Select Lotto Options → Jokeri CSV…

Data file

The program reads data\JokeriData.csv. The file has 7 columns, one for each digit position, separated by semicolons. Values are single digits 0–9.

Dialog settings

  • Number of Rows – Number of suggestion rows to generate (1–50, default 5).

Output

  1. The requested number of prediction rows, each containing 7 digits (0–9). Repeated digits are allowed on the same row, just as in an actual Jokeri draw.
  2. Statistical analysis of all 7 columns (see Statistical Analysis).

Special characteristics

FeatureDescription
Repeated digits allowed The same digit (0–9) may appear in more than one position on the same row.
Zero (0) is a valid value Unlike all other game types, zero is a perfectly normal digit for any of the 7 positions in Jokeri.
Harmonic mean shown as N/A If a column contains even one zero value, the harmonic mean cannot be calculated (division by zero). The program displays N/A in that case.
