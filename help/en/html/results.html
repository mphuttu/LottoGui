Saving and Printing Results

All prediction rows and statistics generated by LottoGui are displayed in the main window as a structured report designed around an A4 portrait page. The report is centered in the client area when there is enough room and uses Segoe UI throughout. It includes the selected game, input details, grouped prediction rows, and clearly separated sections that always appear in this order: prediction summary, statistical analysis, detailed predictions, and conclusions. The conclusion notes that historical draw results do not guarantee or predict future outcomes. After checking results, prediction rows also show matches and the game-specific prize result. The print layout adds page breaks based on the printable area and repeats section and statistics-table headings on continuation pages. Print preview and paper output use the same layout. The presentation does not change any calculations.

Ticket cost

The header above game predictions shows the selected price per row and the total for all generated ticket rows. This count includes the base predictions, additional rows from selected strategies, Wheel combinations, and Jokeri repeated-profile rows. Game-specific prices and add-ons are selected in the same dialog as the prediction-row count.

Checking prediction rows

After generating predictions, select Lotto Options → Check results…. Enter the drawn numbers and click Check. Separate numbers with spaces, commas or semicolons. For games with stars or another bonus number, separate the bonus numbers with a vertical bar, for example 11 17 20 22 35 | 4 8. Each prediction row shows its match count and the matching numbers. Eurojackpot main and star matches are shown separately, for example 1 + 1 correct (matches: 42 (main numbers); 5 (star numbers)). Jokeri digits match only in the same position. The optional Jokeri Double applies only when the last digit also matches. Enter all seven Jokeri digits in draw order.

Saving

  • File → Save – Saves the results to the current file.
  • File → Save As… – Saves the results to a new file. Choose the name and location using the file dialog.

Printing

  • File → Print… – Opens the print dialog and sends the results to the selected printer.
  • File → Print Preview – Preview the print layout before printing.
  • File → Print Setup… – Change printer settings (paper size, orientation, etc.).

Generating new results

When you select a new game mode from the menu and click OK, the main window content is replaced with the new results. Save your previous results before running a new analysis if you want to keep them.

Tip: File → New clears the current result view. You can start with a clean slate before running a new analysis.
