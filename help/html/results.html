Tulosten tallennus ja tulostus

Kaikki LottoGui-ohjelman luomat ennustusrivit ja tilastot näytetään pääikkunan asiakasalueella Consolas-fontilla. Näitä tuloksia voidaan tallentaa tiedostoon tai tulostaa.

Tallentaminen

  • File → Save – Tallentaa tulokset nykyiseen tiedostoon.
  • File → Save As… – Tallentaa tulokset uuteen tiedostoon. Valitse nimi ja sijainti tiedostohakemistikkunan kautta.

Tulostaminen

  • File → Print… – Avaa tulostusikkunan ja tulostaa tulokset valitulle tulostimelle.
  • File → Print Preview – Esikatsele tulostusasettelu ennen tulostamista.
  • File → Print Setup… – Muuta tulostusasetuksia (paperin koko, suunta jne.).

Uusien tulosten luominen

Kun valitset uuden pelimuodon valikon kautta ja napsautat OK, pääikkunan sisältö korvataan uusilla tuloksilla. Tallenna aiemmat tulokset ennen uuden analyysin ajamista, jos haluat ne säilyttää.

Vinkki: File → New tyhjentää nykyisen tulosnäkymän. Voit aloittaa puhtaalta pöydältä ennen uuden analyysin ajamista.
